KOKO ART LIFE STUDIO — FREE WEBSITE STARTER

Open index.html in a browser to preview the site.

To publish free:
1. Create a free GitHub account.
2. Create a new repository named koko-art-life-studio.
3. Upload index.html and the images folder.
4. In Settings > Pages, select "Deploy from a branch", choose main and /root.
5. GitHub will provide a free .github.io website address.

Before publishing, replace:
- hello@kokoartlife.com with your real email
- $POA, artwork sizes and medium/framing details
- the temporary About Koko text with your artist story
- any artwork names/details as needed

The website is static, responsive and does not require paid website hosting.
